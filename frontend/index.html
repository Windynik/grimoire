Deck Forge

Forge Deck builds instantly from the rules engine — no AI needed. With a local model running (via Ollama), Let the AI Forge hands your collection to the model and lets it write the decklist itself, card by card.

Colors (none = auto)

The local AI writes the deck for the format selected above, choosing the actual cards from your collection. Every pick is verified to be real and owned.

Deck explanations run on a local model via Ollama — nothing ever leaves your machine. To enable it:

  1. Install Ollama: brew install ollama (or grab the app from ollama.com)
  2. Pull a model: ollama pull llama3.1:8b (~5 GB, one-time)
  3. Make sure it's running: ollama serve (the desktop app runs automatically)

Then hit re-check — the forge will grow an Explain with Local AI button.
