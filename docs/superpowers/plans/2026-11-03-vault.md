# The Vault (Collection Redesign) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Collection screen with "The Vault" (insights ledger, fanned spotlight, index sidebar with live facets and keyword search, tactile tilting cards, side drawer, Sets completion view), add a first-run welcome flow with a sample collection, and switch the app's fonts to Cinzel Decorative + Spectral + Geist.

**Architecture:** New backend module `backend/core/collection_query.py` holds the price helper, keyword parser, filtering, facets, sorting and insights over a collection hydrated from the card index; new routes live in `backend/api/collection_routes.py`. The frontend replaces `frontend/js/collection/viewer.js` with a set of focused modules under `frontend/js/collection/` (screen orchestrator, hero, index sidebar, results, drawer, sets, state) and a new `frontend/js/welcome/welcome.js` screen. The working mockups are the visual reference.

**Tech Stack:** FastAPI 0.115, Python 3.9 syntax; vanilla JS ES modules and CSS, no build step; Node 22 `node:test` with the jsdom harness.

**Spec:** `docs/superpowers/specs/2026-11-03-collection-redesign-design.md` (binding), plus `docs/superpowers/specs/2026-11-02-forge-agent-and-app-refresh-design.md` §3 and §8 (motion, local-only, textContent rules).

**Layout note:** where the spec (§4.1) describes a top toolbar with chip menus, the approved mockup replaced it with a sticky left **index sidebar** plus a sticky results header; build the mockup's layout.

**Visual reference (read, do not copy blindly):** `frontend/mockup/collection.html` (the Vault), `frontend/mockup/welcome.html` (first run), `frontend/mockup/fonts.js`. These files are git-ignored mockups served by the app at `/mockup/…`. Production code must follow the app's rules: tokens, `h()` + textContent, `cardImg` from `frontend/js/shared/images.js` for every card image, `shared/motion.js` for JS motion and reduced motion, the CSS lint in `tests/js/css.test.mjs`.

## Global Constraints

- Local only; the server binds to `127.0.0.1:8133`.
- Fonts (owner's choice): display `"Cinzel Decorative", Georgia, serif` (weight 700; headings ≥ 22 px only), serif `"Spectral", Georgia, serif` (500, italic 500), UI `"Geist", system-ui, sans-serif` (400–800). Tokens `--font-display`, `--font-serif`, `--font-ui`. Plain Cinzel, Inter, Cormorant, Marcellus, Figtree and IBM Plex Mono are retired everywhere.
- Colors: tokens only; gold `#e8c26a`, violet `#9b8cff`, green `#6fd39a` appear only in `tokens.css`.
- Motion: `var(--dur-*)` tokens; transitions/keyframes move only `transform`/`opacity`; every animation has a reduced-motion fallback that shows the final state; only `shared/motion.js` calls `.animate(` or queries `prefers-reduced-motion`; animations never delay results or block input. Pointer-driven tilt uses inline `transform` (no transition on `transform` while tracking) and is off under reduced motion and on coarse pointers.
- Text from the server goes in with `textContent`/`h()`; the only `innerHTML` is mana markup.
- Card images: `cardImg(card, …)` / `cardImage(card, …)` only.
- Price (spec §7.1): `unit_price(prices, foil)` — foil: usd_foil, usd, eur, tix; non-foil: usd, usd_foil, eur, tix; first numeric > 0, else 0. Totals = unit × quantity.
- Never write to the real `.scryfall_cache/` in tests. Tests: `python -m pytest -q`, `npm test` (pristine output).
- Prose: ASD-STE100; commits `feat:`/`fix:`/`test:`/`docs:`; no AI attribution lines.

## Review Focus

1. **A collection of 3,000 rows:** search with facets answers in < 300 ms (measure in a pytest with synthetic data). Pinned in Task 3.
2. **Facets with a selection inside the same facet:** "Creature" selected → the Type menu still shows real counts for Instant etc. (counts ignore their own facet). Pinned in Task 3.
3. **No card data yet / no collection yet:** Home and Collection send the owner to the welcome flow, never to a broken screen; "Skip" opens the archive. Pinned in Task 10.
4. **Archive mode:** search keywords, sort, grid/list, density and the drawer work; insights, shelves, facet counts, value and Sets are hidden. Pinned in Tasks 7 and 8.
5. **Remembered state that no longer fits** (a removed collection, a stale filter value): the screen falls back to defaults without errors. Pinned in Task 6.

### Task 3: Smart search, facets, and the collection endpoints (backend)

**Files:** Modify `backend/core/collection_query.py`; create `backend/api/collection_routes.py` (included in `main.py` before the static mount); modify `backend/api/routes.py` (archive search uses the parser); tests `tests/test_collection_query.py`, `tests/test_api_collection.py`.

**Interfaces:**
- `parse_query(q: str) -> Query` — keywords per spec §4.2: `t:`, `o:` (quotes), `c:` (includes all; `c:c` colorless), `mv:` (`3`, `2-4`, `5-`), `r:`, `s:`, `f:`, `$>N`/`$<N`/`$>=N`/`$<=N`, `foil`, `dupes`, `new`; everything else is name text (all words must match). Unknown `x:` tokens are name text.
- `Filters` (multi-value, OR inside, AND across): `colors` (buckets), `rarity`, `type` (Creature, Instant, Sorcery, Artifact, Enchantment, Planeswalker, Battle, Land), `mv` (0–6, "7+"), `format`, `set`, `min_price`, `foil` (bool), `dupes` (bool).
- `search(cards, query, filters, sort, new_keys) -> (results, facets, value)` — `facets[name]` counts (quantity-weighted) for every value, computed with all filters except that facet; `value` = sum of value over results. Sorts: `price` (desc), `price_asc`, `name`, `mv`, `color` (W,U,B,R,G,M,C then name), `rarity` (mythic→common, then price), `set`, `edhrec` (rank asc, missing last).
- `GET /api/collection/{job_id}/search` — query params `q, sort, limit (≤200), offset, colors, rarity, type, mv, format, set` (comma-separated), `min_price, foil, dupes`; returns `{cards, total, offset, limit, facets, value}` (cards are `owned_cards` dicts with `owned: true`, `new: bool`). The old parameters `card_type, color, foil, format` keep working (mapped onto the new filters) so the deck editor's search does not break.
- `GET /api/collection/{job_id}/insights` → `insights()` plus `{name, created, card_data_date, has_previous}`.
- `GET /api/cards/search` (archive) also parses `q` keywords (`new`, `dupes`, `foil` ignored); no facets, no value.

- [ ] Step 1: Failing tests: each keyword (incl. quotes, ranges, `$>=`), name words AND, unknown tokens; OR within / AND across; facet counts ignore their own facet (Review Focus 2); sorts; old params still work; insights route; 404 for an unknown job; archive keyword search; performance: 3,000 synthetic rows, search + facets < 300 ms (Review Focus 1).
- [ ] Step 2: FAIL. Step 3: Implement (load the index once per request; cache `owned_cards` per (job_id, collection file mtime, index identity) in a small LRU so repeated searches skip the merge). Step 4: PASS.
- [ ] Step 5: Commit `feat: add keyword search, live facets, and insights for collections`.

### Task 4: Shelves, sets, deck usage, and the sample collection (backend)

**Files:** Modify `backend/api/collection_routes.py`, `backend/core/collection_query.py`, `backend/api/routes.py` (sample import); tests `tests/test_api_collection.py`.

**Interfaces:**
- `GET /api/collection/{job_id}/shelves` → `{spotlight, valuable:[≤12], foils:[≤12], new:[≤12]}`. Spotlight: from rare/mythic cards sorted by name, index = days since 1970-01-01 (local date) mod count; null when none. Valuable/foils/new: unique by (id, foil), by unit price desc. `new` uses the next-older collection (by `created`).
- `GET /api/collection/{job_id}/sets` → `[{code, name, owned, total, value, art_id}]`: `owned` = distinct names owned in the set; `total` = distinct names of game cards (`backend.forge.cards.is_game_card`) in the index for that set; `art_id` = the most valuable owned card's id. Sorted by owned/total desc.
- `GET /api/collection/{job_id}/sets/{code}` → `{code, name, total, owned, cards:[{scryfall_id, name, mana_cost, type_line, rarity, collector_number, image_url, price, quantity, foil}]}` — one entry per name (the owned printing when owned, else the first printing), ordered by collector number (numeric part) when present, else name.
- `GET /api/decks/usage?ids=a,b` → `{id: [{deck_id, name}]}` for decks holding the id in any section or as commander (≤ 200 ids).
- `POST /api/process/sample` → the same SSE stream as `/api/process/stream`, reading `examples/ManaBox_Collection.csv` from the repo, stored with the name "Sample collection".

- [ ] Step 1: Failing tests for each route (spotlight stable within a day and changing across days with an injected date; new vs previous collection; set totals ignore tokens; checklist order; usage; sample stream ends with `done` and stores "Sample collection").
- [ ] Step 2: FAIL. Step 3: Implement. Step 4: PASS.
